# SYNC_PianoRoll

MIDIなどの音楽ファイルから鍵盤とノートを描画するAviUtl2用プラグインです。
「ピアノロール」というメディアオブジェクト1つで音楽ファイルと表示設定を管理します。

## 導入方法

1. AviUtl2を終了します。
2. 配布ZIPのSYNC_PianoRollフォルダーを `C:\ProgramData\aviutl2\Plugin` へ配置します。
3. AviUtl2を起動します。

必要なプラグインは `SYNC_PianoRoll_Filter.auf2` 1本です。
旧フィルターと同じファイル名で上書き更新します。入力プラグインとObjectフォルダーは配布しません。
以前のSYNC_PianoRoll_Input.aui2や、一時的に配布したSYNC_PianoRoll.auf2が残っている場合は削除してください。
β版のため旧配置との互換性はありません。

## 使い方

1. メディアオブジェクトから「ピアノロール」をタイムラインへ追加します。
2. 設定欄の「音楽ファイル」でMIDI等を指定します。
3. 「描画方式」「表示タイプ」「方向」や音域・色を調整します。
4. **3Dでは、ピアノロールが対象になるよう上のレイヤーに「カメラ制御」を配置します。**

2Dはカメラ制御なしで使えます。3Dの正しい前後関係にはカメラ制御が必要です。
位置・回転・拡大等は標準の映像再生設定で調整できます。
音声は出力しないため、必要な音声素材を別に配置してください。

「描画幅」「描画高さ」は0ならシーン寸法です。個別に指定することもできます。
「開始位置 (秒)」「再生速度 (%)」で音楽データの参照時刻を調整します。
再生速度は現在の倍率を掛ける方式です。途中で速度を変えて連続的に積算する用途には対応しません。


## 表示方式

- 2D：縦／横。表示タイプによらず同じ縦横描画です。
- 3D Type1：縦／横の平面配置。
- 3D Type2：内向き／外向きの円環配置。
- 3D Type3：内向き／外向きの円筒配置。

白鍵・黒鍵・ノートの3D厚みの初期値は30・20・20です。
半透明レーンや発光の重なりには、引き続き改善を検討している部分があります。

## 対応ファイル

現在、次の音楽ファイルに対応しています。

| 種類 | 拡張子 |
| --- | --- |
| MIDI | `.mid`、`.midi` |
| UTAU | `.ust` |
| VOCALOID | `.vsq`、`.vsqx` |
| MusicXML | `.musicxml`、`.mxl`、`.xml` |
| MuseScore | `.mscx`、`.mscz` |
